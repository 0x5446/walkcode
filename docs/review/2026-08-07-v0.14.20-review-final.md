## 已修复（commit 670bf9b）

1. **跨回合去重丢回复**（correctness + goalfit 双维度命中，本方脚本复现证实）
   `last_visible_text` 活满整条排水循环，而 codex 监听器跨回合常驻（ADR 0060）。
   复现：同一次排水内两个 `TURN_COMPLETED{message:"同一个答复"}` → 只投递 1 条。
   已改为按回合作用域（`turn_ended` 标志，回合结束事件处理完清空）。
2. **纯空白输出仍静默**（goalfit）
   复现：`TURN_DELTA{"   \n"}` + 空完成 → 0 条告警，且投递了一个空气泡。
   已改用 `visible_text.strip()`。核实过：排水可达的所有 view 类型无一渲染为纯空白。
3. **tag 兜底越过 Release 门禁**（goalfit + conventions 双维度命中）
   `git ls-remote` 列 tag 会选中"有 tag 无 Release"的版本（release.sh 先推 tag
   再建 Release）。已换成 `releases/latest` 的 302 跳转解析；三源产出统一过
   `vX.Y.Z` 校验。实测三源均返回 v0.14.19。
4. **文档缺失**（conventions）→ 新增 ADR 0061，同步 AGENTS.md 与 walkcode-release skill。
5. **测试未走真实协议**（conventions + maintainability 双维度命中）
   新增经 `CodexAppServerTransport` 转换的用例（`event_msg/task_complete{null}`
   与 JSON-RPC `turn/completed` 两种线格式）；连续两空轮改为同一次排水内断言。
6. **`_compose_turn_text` 三入口**（maintainability Suggestion）→ 收敛为单一模块级函数。
